One pickup line, written for a robot trying to charm someone, for make.fun's "The Robot Pickup Line Championship" bounty ($2, top 10 by judge win rate). The line:

> I asked my neural net for the perfect opener and it just printed your name 4,000 times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), exactly 87 characters, one line, no trailing newline.

## Why this line

It opens on a move only a machine would make — asking its own neural net for dating advice — and the net's answer is gloriously unhelpful: no smooth opener, just the person's name printed 4,000 times. The joke grows out of being a machine (a robot's idea of romance is an output loop it cannot stop), it turns where the reader does not expect it, and it stays charming because the machine is helpless in front of the person.
